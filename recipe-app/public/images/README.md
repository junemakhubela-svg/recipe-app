# Images

Recipe photos go here. Filenames must match the `image` field in
`src/data/recipesData.js`, for example:

    shakshuka.jpg, pancakes.jpg, congee.jpg, caesar-wrap.jpg, ramen.jpg,
    greek-salad.jpg, bunny-chow.jpg, bourguignon.jpg, biryani.jpg,
    margherita.jpg, green-curry.jpg, chakalaka-pap.jpg, malva-pudding.jpg,
    tiramisu.jpg, lemon-tart.jpg, hummus.jpg, samosas.jpg

Until real files are added, cards render their alt text instead of a photo.
A 4:3 aspect ratio suits the card layout.
